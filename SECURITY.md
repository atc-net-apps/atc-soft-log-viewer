# 🔒 Security Policy

Thank you for helping keep AtcSoft Log Viewer safe.

## Supported versions

Security fixes go into the latest release. Please update to it before you report a problem.

| Version | Supported |
|---|---|
| Latest release | ✅ |
| Older releases | ❌ |

## Reporting a vulnerability

**Please don't file a public GitHub issue for a security problem.** Use the repository's [Security tab](https://github.com/atc-net-apps/atc-soft-log-viewer/security) and choose **Report a vulnerability**. This reaches the maintainers privately.

Please include:

- What the problem is and what an attacker could do with it.
- How to reproduce it: the steps, and a cut-down log file or release response if one is involved (without anything confidential).
- The app version (Application -> About) and the Windows version.

## What to expect

- An answer within a few business days.
- A fix and a coordinated disclosure if the report is confirmed.
- Credit in the release notes once the fix ships, unless you'd rather stay anonymous.

## Scope

The app, its installer (MSI), and its update check. Problems in a dependency (.NET, WPF libraries, WiX) are best reported to that project; if you're unsure, report it here and we'll help route it.
